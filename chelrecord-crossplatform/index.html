Camera & iPhone

Picture-in-picture
Select a camera to test it.
Connect iPhone or phone camera
iPhone on Mac: Turn on Continuity Camera in iPhone Settings → General → AirPlay & Continuity. Use the same Apple Account, turn on Bluetooth/Wi-Fi, then optionally connect by USB and tap Trust. Select the iPhone from Camera source when macOS exposes it.

Windows: Set up your phone as a connected/virtual webcam in Windows. If Windows detects it as a camera, ChelRecord can select it.

This build uses the system webcam interface; it does not implement a separate proprietary direct USB video driver.
