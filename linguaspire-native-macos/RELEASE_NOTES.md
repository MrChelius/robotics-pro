# LinguaSpire 2.9.0 RC1

- Native macOS Swift/AppKit shell with WKWebView.
- Universal macOS binary for Apple Silicon and Intel.
- Native camera and microphone permissions and sandbox entitlements.
- Improved offline and reconnect experience.
- One-time phone-camera pairing codes.
- Server-side room password and waiting-room enforcement.
- Argon2id password hashing and API rate limits.
- Improved translated captions with lower chunk latency.
- Caption-delivery telemetry in Network Test.
- Privacy/transcription notices, accessibility improvements and core 8-language UI localization.
- Developer ID signing and Apple notarization pipeline prepared for owner credentials.
